# TikTok Plus

[English](README_en.md)

为 TikTok 网页版添加键盘快捷键、评论逐条翻译和翻译全部。

## 快捷键

### 播放控制

| 快捷键 | 功能 |
| --- | --- |
| `Space` | 暂停 / 播放当前视频 |
| `↑` / `↓` | 切换到上一个 / 下一个视频 |
| `←` / `→` | 后退 / 前进 5 秒 |
| `H` / `F` | 影院全屏（含右侧工具栏） |
| `Esc` | 退出全屏；快捷键面板打开时则关闭面板 |

### 互动

| 快捷键 | 功能 |
| --- | --- |
| `Z` | 点赞当前视频 |
| `X` | 打开评论区 |
| `C` | 收藏当前视频 |
| `V` | 复制当前页面标题和链接 |
| `B` | 开关弹幕（如果页面提供对应控件） |
| `R` | 标记为不感兴趣 |
| `G` | 关注作者 |

### 搜索与帮助

| 快捷键 | 功能 |
| --- | --- |
| `Shift + F` | 聚焦搜索框 |
| `Shift + ?` | 显示 / 隐藏快捷键面板 |

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)。
2. 在脚本管理器中新建用户脚本，将 [`tiktok_plus.js`](tiktok_plus.js) 的全部内容粘贴进去并保存。
3. 打开或刷新 [TikTok 网页版](https://www.tiktok.com/)。

## 使用说明

- 脚本仅匹配 `https://www.tiktok.com/*`。
- 多数快捷键在输入框等可编辑控件聚焦时会停用，以免干扰输入；`Esc`、`Shift + F` 和 `Shift + ?` 仍可触发。
- 互动操作依赖 TikTok 页面当前提供的控件；TikTok 更新页面后，个别快捷键可能需要适配。

### 影院全屏

- `H` / `F` 进入影院全屏：整页进入浏览器全屏，当前视频卡片与右侧互动工具栏一起居中排布在黑底上，再按一次或按 `Esc` 退出。
- 视频按原始比例完整显示：竖版视频左右、横版视频上下补黑边，不会拉伸变形或裁掉画面。窗口尺寸变化、视频切换后自动重新计算。
- 右侧工具栏（头像与关注、点赞、评论、收藏、分享、音乐）在全屏内可见可点，与页面上的按钮行为一致。
- 「⋯」菜单在全屏内正常可用：倍速、小窗播放、字幕、不感兴趣、举报都能打开并点击。此前仅把播放器卡片设为全屏，TikTok 的菜单弹层挂在该卡片之外，因此会「点了没反应」；现在改为整页全屏，弹层留在全屏范围内。
- 左下角视频信息和工具栏在停止操作约 2.4 秒后自动淡出，鼠标移动、点击、滚轮或按键时立即恢复。以下情况不会自动隐藏：视频暂停、菜单已打开、快捷键面板打开、正在输入，或鼠标停留在信息区/工具栏上。
- 按 `X` 打开评论时，右侧评论栏在全屏内正常显示，播放器与工具栏会扣除其宽度重新居中；关闭评论后恢复居中。
- 页面原有的导航栏、侧边栏和推荐列表在全屏期间隐藏，退出后完全还原，不影响页面自身播放器。
- TikTok 目前把画面绘制在超分 canvas 层、并将 `<video>` 设为透明，脚本会在全屏期间改用视频层并按 `contain` 取景。
- 若浏览器拒绝全屏请求（例如未获得用户手势或站点策略限制），会退回点击页面自带的全屏控件；两者都不可用时提示 `Fullscreen not allowed`，不会静默失败，也不会残留全屏布局。

## 评论翻译

- 主评论和展开后的回复正文下方会出现“翻译”按钮；空评论、纯图片和纯表情不显示。
- 点击后使用 Google 翻译为简体中文；“查看原文” / “查看译文”可来回切换，同一视频及本地持久化缓存中的译文会复用，滚动导致节点替换或关闭重开评论区也无需重复请求。
- 评论标题旁的“翻译全部”会翻译已加载的主评论和展开回复，随后随滚动加载、手动展开回复继续翻译。不会主动滚动或展开全部回复；标题结构无法识别时，仅保留逐条翻译。
- “全部查看原文”恢复原文并停止自动翻译，再次开启复用缓存。逐条查看原文的选择会保留，直到手动查看译文或重新开启总开关。
- 总开关在当前视频内保留：关闭评论区暂停派发新评论任务，重开继续；切换视频或刷新页面后关闭总开关。已经完成的译文可从持久化缓存复用。
- 默认使用与 Forum Translator 相同的 Google Chrome 扩展风格接口：`/translate_a/t?client=dict-chrome-ex`。同一文本共享进行中的请求，最多 6 个并发请求，并设置页面级 60 次/分钟滚动配额（非 Google 官方配额）；长评论按最多 900 字符的 Unicode 安全分段翻译。手动翻译优先于批量任务，已加载评论随阅读自动处理。
- 译文保存在 Tampermonkey 本地存储，默认 30 天有效，最多 500 条、50 万译文字符；切换视频、刷新页面后相同内容无需重新请求。仅在翻译成功后缓存。
- 网络失败、超时及可重试的服务端错误最多额外重试 2 次；Google 返回 429 时全局冷却（60 秒、120 秒、300 秒，优先遵守 Retry-After），连续受限暂停任务，需手动恢复；等待中的任务不主动重复请求。遇到长期限流不能保证自动恢复。
- 翻译失败时保留原文，点击“翻译失败，重试”手动重试。只翻译正文，用户名、图片和原有操作不受影响；诊断事件可在浏览器控制台用 `[TikTok Plus][translate]` 检索。
- 每次首次翻译或重试会将该条评论正文发送到 `translate.googleapis.com`，开启“翻译全部”也会发送后续加载的正文；匿名请求不携带 Cookie。脚本仅申请 `GM_xmlhttpRequest` 和该域名的跨域连接权限，无需 API Key。
- 使用的是 Google 免 Key 非正式接口，非 Google 官方支持的客户端 API，可能限流或失效；翻译质量及服务可用性没有保证，需要网络能够访问该域名。
- 更新已安装脚本时，保存新版本并刷新 TikTok 页面；若脚本管理器提示连接权限，仅允许 `translate.googleapis.com`。

## 验证

用浏览器打开 [`tests/comment-translation.html`](tests/comment-translation.html)，自动运行翻译交互、快捷键与影院全屏回归检查。测试使用模拟响应，不向 Google 发送请求；刷新页面可重新运行。影院全屏用例复刻了 TikTok 的真实结构（工具栏是媒体卡片的兄弟节点、菜单弹层挂在该卡片子树之外），并用 `document.elementFromPoint` 验证菜单项能被真实命中，而不只是 `.click()` 能触发。该测试不能替代 TikTok 实际页面及脚本管理器中的验收。
